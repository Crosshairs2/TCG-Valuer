This is a website that shows you all the info of a card, not just the prices. Ever wanted to know the game, generation, artist, and in the future, every attack, ability, description, height, weight, health, and evolution? Now you can!

  • Name
  • Market Price ($)
  • Set Name
  • Listed ID (# out of #)
  • Actual ID (# out of # including secret rares)
  • Series (Game generation)
  • Rarity
  • National Pokedex #
  • Card Artist
  • Website ID (Set ID-Card ID, base1-4 means the set ID is base 1 and the card ID is 4)

The data is from the API provided by Pokemon TCG API, which uses prices from TCGplayer, the community standard/most accurate for determining prices of TCGs.
