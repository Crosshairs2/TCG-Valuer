IIWITCG

Is It Worth It TCG

This website will show data for a given TCG product, so you can easily see, "Should I open it, or should I keep it sealed". The data shown is as follows:

  • Minimum Value
  • Average Value
  • Maximum Value
  • Minimum Profit
  • Average Profit
  • Maximum Profit
  • Market Price
  • MSRP

The data is from the API provided by Pokemon TCG API, which uses prices from TCGplayer, the community standard for determining prices of TCG collectables.
